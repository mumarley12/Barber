# Agenda por Barbeiro — protótipos

Protótipos interativos exportados do Claude Design. Ainda não há backend: os horários são simulados e nada é salvo.

| Arquivo | O que é |
|---|---|
| `Site Mr Chavozo.dc.html` | Site da barbearia (demo) com agendamento em 4 passos |
| `Painel Barbearia.dc.html` | Painel do dono: agenda do dia, folgas, serviços e relatório |
| `LP Agenda por Barbeiro.dc.html` | Página de vendas do serviço |
| `Mobile Preview.dc.html` | Site e painel lado a lado em molduras de celular |
| `assets/` | Logo e vídeos do hero |
| `uploads/` | Prints de referência usados no design |

`support.js` e `image-slot.js` são o runtime dos arquivos `.dc.html`. Para ver localmente, sirva a pasta por HTTP (ex.: `python3 -m http.server`) e abra os `.dc.html` no navegador.
